# Clean holdout: agent vs baseline (2026-10-27)

> Scored at component level (component and failure mode), the definition at the time. Every run rescored at pole level: [2026-10-28_pole_level.md](2026-10-28_pole_level.md).

These are the reported numbers. The clean holdout (scenarios/holdout_clean.yaml) is every single fault never used before:
91 possible faults minus the 8 hand-written scenarios minus the 40 dev holdout faults = 43 faults (38 visible, 5 latent).
The agent prompt and the baseline rules were frozen before this run and were not changed after it
(fingerprints recorded in each results.json: prompt a194ad85aaa1, baseline 1e6a729e4428).

Agent: muse-spark-1.3, reasoning effort low, approvals denied (batch default). Baseline: deterministic golden-twin half-split.
For latent faults insufficient_information counts as correct. "Justified" adds cases where the true fault is an observational
twin of another fault (all observations identical, recomputed with the sequence-based motor model) and the answer was
insufficient_information or the twin. "Confidently wrong" = a submitted diagnosis that is neither correct nor justified.

Single run per case; the reruns below show that individual cases flip between runs, so read differences of 1 or 2 cases as noise.

## Failure analysis, agent (clean, every case not correct)

- c05, c08, c15, c18 (welded L1 or L3 main pole of KM1 or KM2): the opposite direction ties L1 to L3, FU2 blows, what is left
  hums and the thermal relay trips. These are the confidently wrong answers. The agent either named the blown fuse (the
  consequence, not the cause: c18 "FU2 1-2 open"), reasoned that reverse only uses KM2 and never measured KM1's poles
  (c05 "KM2 stuck_open"), or named a neighbouring part (c08, c15). The "protection operated" note at the moment of the start
  press was the key clue it did not use. Reruns: 2/3, 2/3, 2/3, 0/3 correct, so this class is solvable but unreliable.
- c02 (QF1 pole 5-6 open): insufficient_information. It suspected the right line but the ohmmeter cannot test a breaker
  pole with the breaker off, and re-powering after the thermal trip was denied. Reruns: 2/3 deny, 3/3 approve.
- c09, c23, c35: justified. Each truth has an observational twin (welded start button vs welded self-hold contact on the
  same two nets; KM3 coil short vs KT coil short through closed NC contacts) and the agent said insufficient_information.

## Failure analysis, baseline (clean)

- c05, c08, c15, c18: names the blown fuse FU2 1-2 (the consequence) every time: its half-split follows the dead phase and
  stops at the first open part.
- c09, c35: picks a wrong member of a twin pair (its sweep stops at the first parallel path); c21 (KM2 53-54 welded) and
  c12 (KM2 welded) end in the same sweep and blame KM1 parts.
- c24, c25, c27, c29 (one star or delta main pole open): no rule covers an incomplete star or delta bridge and the resistance
  sweep finds nothing at rest: insufficient_information.
- c30 (KT 55-56 welded): the half-split lands on KM3 21-22 and the welded-contactor check does not apply.

22/24 correct, longest run 21 turns: the 30-turn loops seen in the first dev runs are gone (text tool-call recovery, turn budget,

## Simulator change before this run

The motor model now derives the motor state from winding currents (nodal analysis, positive and negative sequence components)
and reports line currents in amps (clamp meter, 10 A rated in delta). Before, any non-standard winding connection was shown as
"stopped, zero current" (dev case h30). A welded delta-contactor pole while the star contactor is closed is not a phase-to-phase
short: every path between two phases still runs through a winding. It bypasses one winding and puts 400 V on the other two;
the field stays balanced, so the motor runs in star with unbalanced currents (10 A on the tied line, 5.8 A on the others,
3.3 A when healthy). True bolted shorts happen when contacts tie two supply phases directly (a welded KM1 or KM2 L1/L3 pole
plus the opposite direction); FU2 blows there, as before. tests/test_power_faults.py covers every welded and stuck-closed
power contact.
