### What the information-gain baseline is, and why it is not a fair peer

It keeps every one of the 91 single faults the catalog defines as a candidate, simulates each candidate in lock step
with the real panel, and at every step takes the measurement or panel action whose predicted outcomes split the
surviving candidates best (smallest expected number of survivors). A reading a candidate does not reproduce exactly
removes it. It uses the same tools and safety policy as the agent and never re-applies power.

It needs a complete, exact fault model of this very circuit: the list of every possible fault and the same simulator
that produces the readings, so its predictions are never wrong. The agent has none of that: it gets the schematic and
the tool results, and has to reason about what a reading means. Read the information-gain row as an upper bound on
what measurement choice alone can achieve with perfect knowledge of the plant, not as a competitor. Its 3 strict
misses are the observational twins (c09, c23, c35): it ends with the true fault and its twin and answers
insufficient_information, which is the only defensible answer there.

What the comparison does say: the agent's accuracy (30/38) sits between a rule-based half-split (25/38) and the
perfect-model ceiling (35/38, 38/38 justified), and it spends about three times the measurements of the ceiling.
On a real panel nobody has the perfect model, which is the gap the agent fills.

## Image ablation: does the schematic image help?

The frozen agent was run on the same 43 faults with the text netlist only (no image part; the sentence saying an
image shows the same circuit was dropped, nothing else changed).

- Same score: 30/38 visible (33/38 justified), 5/5 latent, in both conditions.
- 33 cases correct in both; 2 correct only with the image (c06, c12), 2 correct only without it (c02, c05), 6 wrong
  in both. c02 and c05 already flipped between earlier reruns, so this is run-to-run noise.
- Without the image the agent took more measurements (9.8 vs 8.3 per case) and cost slightly more ($0.077 vs $0.068
  per case), one run each.

Conclusion: on this circuit the schematic image adds no measurable accuracy; the text netlist carries the information
the agent uses. The image stays in the UI (people read it) and in the first request (it is sent once and is cheap).
